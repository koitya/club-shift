# 軽音楽部 部室シフト

バンドごとに部室の練習希望を出して、公平に自動で割り当てて、確定したシフトを全員で見るためのWebアプリです。スマホで使う前提で作っています。

## 仕組み

```
スマホ ──→ 画面（GitHub Pages）──→ 処理（Google Apps Script）──→ データ（Googleスプレッドシート）
```

| 部分 | 置き場所 | 料金 |
|---|---|---|
| 画面 | このリポジトリの `public/`（GitHub Pagesで自動公開） | 無料 |
| 処理 | 部用Gmailのスプレッドシートに付いた Apps Script（`gas/Code.gs`） | 無料 |
| データ | 同じスプレッドシート | 無料 |

## フォルダ構成

```
public/            画面（ここを直すと自動で公開される）
  index.html       画面の骨組み
  style.css        見た目
  app.js           画面の動き
  config.js        ★Apps ScriptのURLを書く場所
gas/Code.gs        Apps Scriptに貼るサーバー側のコード
docs/              説明書
.github/workflows/ GitHub Pagesへの自動公開設定
```

## 更新のしかた（ふだん）

1. GitHubで `public/` の中のファイルを開く → ✏（鉛筆）で編集 → 「Commit changes」
2. 1〜2分で自動的にサイトに反映されます（スマホのブラウザからでもできます）

`gas/Code.gs` を変えたときだけ、Apps Script側でも貼り直しと再デプロイが必要です（[セットアップ手順](docs/セットアップ手順.md) の「サーバー側を更新するとき」）。
