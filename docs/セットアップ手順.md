# セットアップ手順（最初に1回だけ）

所要時間：30分くらい。**PCでやるのがおすすめ**です（Apps Scriptの画面がスマホだと使いにくいため）。ふだんの運用はスマホだけでできます。

---

## A. 部用のGoogleアカウントを用意する

1. 部用のGmailを1つ作る（例：`xxx.keion.club@gmail.com`）
2. ログイン情報は顧問の先生と部長で共有して、代替わりのときに引き継ぐ

> 学校のGoogleアカウントは使わないでください。外部公開が禁止されていることがあるし、卒業でアカウントが消えるとデータも消えます。

## B. スプレッドシートとApps Scriptを作る

1. 部用Gmailで [Googleスプレッドシート](https://sheets.google.com) を開き、「空白」で新規作成する。名前は「部室シフト」など
2. メニューの **拡張機能 → Apps Script** を開く
3. 最初から入っている `function myFunction() {...}` を全部消して、このリポジトリの `gas/Code.gs` の中身を全部貼り付ける
4. 💾（保存）を押す
5. 上の関数の選択欄で **setup** を選び、**▶ 実行** を押す
6. 「承認が必要です」と出たら：権限を確認 → 部用アカウントを選ぶ →「詳細」→「（安全ではないページ）に移動」→「許可」
   - 自分で作ったスクリプトなので、この警告は出て当然です
7. 下の実行ログに **初期の管理者パスワード** と **部の合言葉** が出る。スプレッドシートの「設定」シートにも書かれている

## C. ウェブアプリとして公開する

1. Apps Script画面の右上 **デプロイ → 新しいデプロイ**
2. ⚙（種類の選択）→ **ウェブアプリ**
3. 次のように設定する
   - 説明：`v1`
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「デプロイ」→ 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/……/exec`）をコピーする

> 「全員」にしてもスプレッドシート自体は公開されません。アプリを通した操作だけができます。

## D. GitHubにURLを設定する

1. このリポジトリで `public/config.js` を開いて、✏（鉛筆）を押す
2. `PASTE_YOUR_APPS_SCRIPT_URL_HERE` を、CでコピーしたウェブアプリのURLに書き換える
3. 「Commit changes」を押す
4. 1〜2分待つと、`https://<ユーザー名>.github.io/<リポジトリ名>/` で使えるようになる
   - 公開の状態は、リポジトリの **Actions** タブで見られる（✅ が出れば完了）
   - GitHub Pagesの設定は **Settings → Pages → Source：GitHub Actions** になっていればOK

## E. 最初の確認

1. サイトを開いて「管理者」タブから、初期の管理者パスワードでログインする
2. 管理 → ⑤設定 で **管理者パスワードを自分で決めたものに変える**（初期パスワードは「設定」シートから自動で消えます）
3. 合言葉も、部員に伝えやすいものに変えておく
4. [テストチェックリスト](テストチェックリスト.md) を一通りやってみる

---

## サーバー側（gas/Code.gs）を更新するとき

**ここだけ注意。手順を間違えるとURLが変わって、サイトが動かなくなります。**

1. Apps Scriptを開いて、`Code.gs` の中身を新しいものに全部置き換えて 💾 保存
2. **デプロイ → デプロイを管理**
3. 今のデプロイを選んで ✏（編集）
4. バージョン：**新バージョン** を選ぶ → 「デプロイ」

❌ 「新しいデプロイ」は押さない（URLが変わってしまう）
もし押してしまったら、新しいURLで D の手順をもう一度やれば直ります。

## 無料枠・注意点

- GitHub Pages：公開リポジトリなら無料。中身（コード）は誰でも見られるけど、パスワードやデータは入っていないので問題ない
- Apps Script：無料のGoogleアカウントでも、部活の規模（30バンド程度）なら上限には届かない見込み
- データはスプレッドシートにあるので、**ファイル → 変更履歴** から過去の状態に戻せる。月に1回「ファイル → コピーを作成」でバックアップを取っておくとさらに安心
- 各サービスの無料条件は変わることがあるので、年に1回くらい確認してください
