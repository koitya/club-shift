# 部室シフトの使い方（部員向け）

サイト：`（ここにURLを書く）`
iPhoneはSafariの共有ボタン →「ホーム画面に追加」、Androidは Chrome のメニュー →「ホーム画面に追加」でアプリみたいに使えます。

## はじめて（バンドで1人がやればOK）
1. 「新規登録」を開く
2. バンド名・パスワード（8文字以上）・**部の合言葉**（管理者に聞く）を入れて登録
3. パスワードはバンドのメンバーと共有する
4. 掛け持ちしている人は、バンドごとに別のアカウントになります

## 練習の希望を出す
1. 下の「✋ 希望提出」を開く（「シフト」画面に赤い「まだ出していません」が出ていたら「今すぐ出す」でもOK）
2. ◀ ▶ で月を選ぶ（受付中のときだけ出せます。締切と「あと◯日」が表示されます）
3. カレンダーの日付をタップするとその日の欄に移動 → 前半・後半をタップ → 押した順に「第1希望、第2希望…」になる。⏰ の日は時間がいつもと違います
4. 順番は ↑ ↓ で入れ替え、✕ で削除
5. 下のオレンジのボタン「**未保存：タップして保存**」を押す → 「保存済み」になれば完了

- 締切までなら何回でも出し直せます
- **候補を多く出すほど、枠をもらえる可能性が上がります**
- 他のバンドからは、あなたの希望は見えません

## 掛け持ちしている人
1. 右上の「👥 切替」→「＋ 別のバンド・管理者でログイン」で、もう一つのバンドでもログインする
2. 以後は「👥 切替」か、希望提出画面の上のバンド名ボタンをタップするだけで切り替えられる（ログアウト不要）
3. シフト画面では、ログインしている全部のバンドの枠がオレンジになる

## シフトを見る
- 「📅 シフト」で確定したシフトが見られる
- 上のカレンダー（月曜始まり）で自分の日がオレンジ。日付をタップするとその日の詳細へ移動
- 自分のバンドの枠はオレンジで表示。「自分のバンドだけ表示」も使える
- 一番上に「次の練習」が出ます

## 困ったとき
- パスワードを忘れた → 管理者にリセットしてもらう
- パスワードを変えたい → 「👤 アカウント」から変更
- バンド名を変えたい → 管理者に頼む
- 決まった枠に行けなくなった → 管理者に連絡（管理者が1枠だけ変更できます）
