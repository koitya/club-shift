# 本番前テストのチェックリスト

本番の前に、管理者1人＋テスト用のバンド3つ（スマホ2台以上）で確認してください。終わったら、テスト用のバンドは ④バンド管理 で停止しておきます。

## アカウント
- [ ] 管理者ログインができる。⑤設定で管理者パスワードを変えられる
- [ ] 合言葉が違うと登録できない
- [ ] バンドを3つ登録できる
- [ ] 同じ名前（大文字・小文字や全角・半角の違いも含む）では登録できない
- [ ] 別のスマホからログインできる
- [ ] パスワードを5回間違えると、10分間ログインできなくなる
- [ ] 管理者がパスワードをリセットすると、そのバンドの他のスマホはログアウトされる

## 月の準備・希望提出
- [ ] 準備中の月は、バンドから希望を出せない
- [ ] 受付中にすると希望を出せる。×にした枠は選べない
- [ ] 希望の並べ替え・削除・保存ができる。もう一度開いても保存した内容が残っている
- [ ] 保存しないで別タブに移ろうとすると確認が出る
- [ ] バンドAの希望が、バンドBの画面に出てこない
- [ ] 締切日時を過ぎると希望を出せなくなる（締切を数分後に設定して試す）

## 割り当て
- [ ] ②提出状況に、提出済み・未提出が正しく出る
- [ ] 自動割り当てをすると「仮」になり、バンドのシフト画面にはまだ出ない
- [ ] 同じ枠を希望した2バンドのうち、片方だけが取っている
- [ ] 同じバンドが同じ日に2枠もらっていない
- [ ] プルダウンで手動変更ができる。同じ日の2枠目は入れられない
- [ ] 一括確定すると、全バンドのシフト画面に出る
- [ ] 確定後に1枠変更すると、すぐにバンド側にも反映される
- [ ] 「確定を取り消す」でバンド側から見えなくなる
