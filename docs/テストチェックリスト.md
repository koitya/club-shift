# 本番前テストのチェックリスト

本番の前に、管理者1人＋テスト用のバンド3つ（スマホ2台以上）で確認してください。終わったら、テスト用のバンドは ④バンド管理 で停止しておきます。

## アカウント
- [ ] 「部長」でログインして、「👤 アカウント」でパスワードを変えられる
- [ ] ⑤設定で幹部を追加でき、追加した幹部が別のスマホからログインできる
- [ ] 2人の管理者が同時にログインしていても、それぞれ操作できる
- [ ] 自分自身・最後の1人の管理者は停止できない。停止した幹部はログアウトされる
- [ ] 「ログ」シートに操作した幹部の名前が残る
- [ ] 合言葉が違うと登録できない
- [ ] バンドを3つ登録できる
- [ ] 同じ名前（大文字・小文字や全角・半角の違いも含む）では登録できない
- [ ] 別のスマホからログインできる
- [ ] バンドは数字4桁のパスワードで登録できる。管理者は8文字未満だと追加できない
- [ ] パスワードを5回間違えると1分、6回で5分…とロック時間が長くなる
- [ ] 管理者がパスワードをリセットすると、そのバンドの他のスマホはログアウトされる

## 月の準備・希望提出
- [ ] カレンダーが月曜始まりで、曜日が正しい
- [ ] 日付タップで丸ごと×、「毎週◯曜を×」でまとめて×にできる
- [ ] 詳細モードで、その日だけ時間を変えられ、「毎週◯曜に反映」で同じ曜日に反映される。部員の画面にもその時間が出る
- [ ] 準備中の月は、バンドから希望を出せない
- [ ] 受付中にすると希望を出せる。×にした枠は選べない
- [ ] 希望の並べ替え・削除・保存ができる。もう一度開いても保存した内容が残っている
- [ ] 保存しないで別タブに移ろうとすると確認が出る
- [ ] 未提出のバンドのシフト画面に「まだ出していません」が出て、提出すると「提出済み」に変わる
- [ ] 1台のスマホで2つのバンドにログインし、「👥 切替」とバンド名ボタンで切り替えられる。それぞれの希望が別々に保存される
- [ ] 「📋 未提出バンドをコピー」でLINEに貼れる文章がコピーされる
- [ ] バンドAの希望が、バンドBの画面に出てこない
- [ ] 締切日時を過ぎると希望を出せなくなる（締切を数分後に設定して試す）

## 割り当て
- [ ] ②提出状況に、提出済み・未提出が正しく出る
- [ ] 自動割り当てをすると「仮」になり、バンドのシフト画面にはまだ出ない
- [ ] 同じ枠を希望した2バンドのうち、片方だけが取っている
- [ ] 同じバンドが同じ日に2枠もらっていない
- [ ] プルダウンで手動変更ができる。同じ日の2枠目は入れられない
- [ ] 一括確定すると、全バンドのシフト画面に出る
- [ ] 確定後に1枠変更すると、すぐにバンド側にも反映される
- [ ] 「確定を取り消す」でバンド側から見えなくなる
