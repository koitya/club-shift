# 管理者マニュアル

サイトを開いて「管理者」タブから **自分の名前とパスワード** でログイン → 下の「🛠 管理」タブを開く。

管理者（幹部）は何人でも作れて、同時に作業してもデータは壊れません。ただ、他の人が変えた内容は「🔄 最新に更新」を押すまで画面に出ないので、作業の前に一度押してください。誰が何をしたかは、スプレッドシートの「ログ」シートに名前つきで残ります。

## 毎月の流れ

| いつ | やること | 場所 |
|---|---|---|
| 月の前半 | 来月の枠を決めて受付開始 | ① 月の準備 |
| 締切前 | 未提出のバンドに声をかける | ② 提出状況 |
| 締切後 | 自動割り当て → 確認・修正 → 一括確定 | ③ 割り当て |
| 確定後 | 急な変更があったら1枠ずつ直す | ③ 割り当て |

画面上の ◀ ▶ で対象の月を切り替えます。

### ① 月の準備
1. **基本の時刻**（前半・後半の開始と終了）を確認する。前の月の設定が自動で入っています
2. カレンダー（月曜始まり）で音楽室が使えない日を×にする
   - 「タップで ○×切替」モード：日付をタップするとその日を丸ごと×（もう一度で○）
   - 「毎週◯曜」を選んで「を×にする」：毎週決まった曜日をまとめて×
   - 「全部○」「土日を×」「全部×」ボタンもあります
3. 時間が違う日・前半だけの日があれば「タップで 詳細・時間」モードにして日付をタップ
   - 前半／後半の○×を切り替えたり、その日だけの時刻を入れて「この日の時間にする」
   - 「毎週◯曜に反映」で同じ曜日に全部コピー（例：水曜は全部短縮）
   - 時間を変えた日には ⏰ が付きます
4. 締切日時を入れる
5. 状態を **受付中** にして「月の設定を保存」（保存するまでカレンダーの変更は反映されません）

締切日時を過ぎると、自動で受付が止まります。

### ② 提出状況
- 赤い「未提出」がまだ出していないバンド
- 「📋 未提出バンドをコピー」→ LINEに貼れば催促メッセージになります（締切とサイトのURL付き）
- 「直近○か月：○回」は、公平性の計算に使う過去の確定回数

### ③ 割り当て
1. **自動割り当てを実行** → 仮の割り当てができる（まだ部員には見えない）
2. 枠ごとのプルダウンで、気になるところを手で直す
3. **一括確定して公開** → 全員のシフト画面に表示される

確定後にプルダウンで変更すると、**すぐに公開内容に反映**されます。
全部やり直したいときは「確定を取り消す」→「自動割り当てをやり直す」。

#### 自動割り当てのルール
- 1周ごとに、各バンド最大1枠ずつ取っていく（ドラフト方式）
- 順番は「直近3か月の確定回数＋今月すでに取った数」が少ないバンドから。同点ならランダム
- 各バンドは、自分の希望の中で「まだ空いていて、同じ日に自分の枠がない」いちばん上の枠を取る
- 希望にない枠は絶対に割り当てない
- 全員が1枠もらうまで、誰も2枠目は取れない

### ④ バンド管理
- **パスワードを忘れた** → 編集 → 新しいパスワードを入れて保存 → そのバンドに伝える
- **名前を変えたい** → 編集で変更（ログインには新しい名前を使う）
- **解散した** → 停止する（過去の記録は残る。消さないでください）

### ⑤ 設定
- 部の合言葉（新入部員がバンド登録するときに必要）
- 公平性で数える過去の月数（初期値3）
- **管理者（幹部）一覧**
  - 新しい幹部：「管理者を追加」で名前と仮パスワードを入れる → 本人に伝える → 本人が「👤 アカウント」でパスワードを変える
  - パスワードを忘れた幹部：編集 → 新しいパスワードを入れて保存
  - 引退した幹部：編集 → 停止する
  - 自分自身と、最後の1人は停止できません

自分のパスワードは「👤 アカウント」から変えられます。

## 困ったとき

| 症状 | 対処 |
|---|---|
| 間違えて確定した | ③で「確定を取り消す」 |
| データがおかしくなった | スプレッドシートの **ファイル → 変更履歴** から戻す |
| 管理者のパスワードを忘れた | 他の幹部に⑤設定でリセットしてもらう。全員忘れたら下記の手順 |
| 「通信できませんでした」が続く | Apps Scriptのデプロイ設定が「全員」になっているか確認 |
| 画面の変更が反映されない | GitHubの Actions タブで ✅ になっているか確認。スマホは再読み込み |

### 管理者が全員パスワードを忘れたとき
1. 部用Gmailでスプレッドシートを開く → 拡張機能 → Apps Script
2. 上の関数の選択欄で **recoverAdmin** を選んで ▶実行
3. 実行ログに新しい管理者（「部長2」など）の名前とパスワードが出る → それでログインして、みんなのパスワードをリセットする

## シートを直接さわるときの注意
- 高速化のため、アプリはシートの中身を一時保存（キャッシュ）して使っています。シートを手で直すと自動でキャッシュが消えるので、ふつうは何もしなくてOK
- **変更履歴から戻したとき**だけは自動で消えないので、スプレッドシートのメニュー **部室シフト → アプリのキャッシュを消す** を押してください（メニューはスプレッドシートを開き直すと出ます）
- アプリが使うシートには保護（警告）がかけてあります
- 列を消したり並べ替えたりすると動かなくなります。値を直すだけにしてください
- 失敗したら「変更履歴」で戻せます
