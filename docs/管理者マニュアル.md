# 管理者マニュアル

サイトを開いて「管理者」タブから管理者パスワードでログイン → 下の「🛠 管理」タブを開く。

## 毎月の流れ

| いつ | やること | 場所 |
|---|---|---|
| 月の前半 | 来月の枠を決めて受付開始 | ① 月の準備 |
| 締切前 | 未提出のバンドに声をかける | ② 提出状況 |
| 締切後 | 自動割り当て → 確認・修正 → 一括確定 | ③ 割り当て |
| 確定後 | 急な変更があったら1枠ずつ直す | ③ 割り当て |

画面上の ◀ ▶ で対象の月を切り替えます。

### ① 月の準備
1. 時刻（前半・後半の開始と終了）を確認する。前の月の設定が自動で入っています
2. 使えない枠をタップして灰色（×）にする。「土日を×」などのボタンでまとめて変えられる
3. 締切日時を入れる
4. 状態を **受付中** にして「月の設定を保存」

締切日時を過ぎると、自動で受付が止まります。

### ② 提出状況
- 赤い「未提出」がまだ出していないバンド
- 「直近○か月：○回」は、公平性の計算に使う過去の確定回数

### ③ 割り当て
1. **自動割り当てを実行** → 仮の割り当てができる（まだ部員には見えない）
2. 枠ごとのプルダウンで、気になるところを手で直す
3. **一括確定して公開** → 全員のシフト画面に表示される

確定後にプルダウンで変更すると、**すぐに公開内容に反映**されます。
全部やり直したいときは「確定を取り消す」→「自動割り当てをやり直す」。

#### 自動割り当てのルール
- 1周ごとに、各バンド最大1枠ずつ取っていく（ドラフト方式）
- 順番は「直近3か月の確定回数＋今月すでに取った数」が少ないバンドから。同点ならランダム
- 各バンドは、自分の希望の中で「まだ空いていて、同じ日に自分の枠がない」いちばん上の枠を取る
- 希望にない枠は絶対に割り当てない
- 全員が1枠もらうまで、誰も2枠目は取れない

### ④ バンド管理
- **パスワードを忘れた** → 編集 → 新しいパスワードを入れて保存 → そのバンドに伝える
- **名前を変えたい** → 編集で変更（ログインには新しい名前を使う）
- **解散した** → 停止する（過去の記録は残る。消さないでください）

### ⑤ 設定
- 部の合言葉（新入部員がバンド登録するときに必要）
- 公平性で数える過去の月数（初期値3）
- 管理者パスワードの変更 → **管理者が交代したら必ず変える**

## 困ったとき

| 症状 | 対処 |
|---|---|
| 間違えて確定した | ③で「確定を取り消す」 |
| データがおかしくなった | スプレッドシートの **ファイル → 変更履歴** から戻す |
| 管理者パスワードを忘れた | 部用Gmailでスプレッドシートを開く → 拡張機能 → Apps Script → 下記の手順 |
| 「通信できませんでした」が続く | Apps Scriptのデプロイ設定が「全員」になっているか確認 |
| 画面の変更が反映されない | GitHubの Actions タブで ✅ になっているか確認。スマホは再読み込み |

### 管理者パスワードを忘れたとき
1. スプレッドシートの「設定」シートで、`admin_salt`・`admin_hash`・`admin_ver` の3行を行ごと削除する
2. Apps Scriptで `setup` をもう一度実行する → 新しい初期パスワードが表示される

## シートを直接さわるときの注意
- アプリが使うシートには保護（警告）がかけてあります
- 列を消したり並べ替えたりすると動かなくなります。値を直すだけにしてください
- 失敗したら「変更履歴」で戻せます
